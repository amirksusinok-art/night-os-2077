# NIGHT_OS // 2077

An interactive mystery told through a fictional operating system. Explore the desktop, recover memories, inspect files, use the terminal, and uncover the ECHO project.

## Run

```bash
npm install
npm run dev
```

Build with `npm run build`. Progress is saved in your browser. Reset it from Settings.

Start in Terminal with `help`, explore Files and Messages, then restore fragments in Memory Archive. The hidden admin panel can be found with Ctrl+Shift+E.
